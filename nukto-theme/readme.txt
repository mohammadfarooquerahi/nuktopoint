Nukto Point is an avant-garde, ultra-dark WordPress theme built from scratch for elite creative studios, art directors, and communication designers, developed by Mohammad Farooque.

== Description ==

Nukto Point is crafted without heavy visual page builders or starter-theme bloat. It features:
* Ultra-dark `#080808` aesthetic with signature electric magenta `#ff00a3` accents.
* Dual-ring magnetic cursor following mouse dynamics.
* Lenis smooth scrolling with GSAP ScrollTrigger orchestration.
* Expanding hero showreel card interaction.
* Real-time Matter.js 2D physics tag-cloud playground.
* Native Custom Post Type 'project' with custom taxonomies, client metadata, and responsive grid layouts.
* AJAX contact form handler with nonce security and HTML email routing.
* Self-contained Google Fonts (Montserrat) and full WordPress Coding Standards compliance.

== Installation ==

1. In your WordPress admin, go to Appearance -> Themes -> Add New.
2. Click Upload Theme and choose `nukto-theme.zip`.
3. Click Install Now and then Activate.
4. Customize settings under Appearance -> Customize.

== Frequently Asked Questions ==

= Does this theme require Elementor or page builders? =
No. Nukto Point is built with lean semantic HTML5, modern CSS custom properties, and native WordPress template architecture.

= How do I add portfolio projects? =
Navigate to "Projects" in the WordPress admin bar, click "Add New", enter the title, description, client name, year, disciplines, and set the Featured Image.
